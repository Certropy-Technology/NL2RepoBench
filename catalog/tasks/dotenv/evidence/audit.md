# dotenv static authoring audit

Status: `blocked` / audit-only. This directory intentionally has no
`task.toml`, Harbor tree, private test bundle, Oracle artifact, or dependency
cache. It is a discovery/inventory record for a future Node task.

- Repository: `https://github.com/motdotla/dotenv`

  `sha256:8847b9563b9c54e1cd420d895c31efa9627f5fd34dd936d0175e0017067e1d3d`
- The source package has a committed npm lockfile, but it is lockfile version 2;
  the current Node authoring validator requires the v3 contract for the pilot.

## Static/API scope

The suitable first scope is deliberately narrower than the complete package:

- `parse(text)` to a JSON object;
- `populate(target, source, options)` with JSON-compatible values;
- deterministic parser edge cases and option handling.

The following are excluded from the candidate boundary: `config()` filesystem
search, mutation of `process.env`, the dotenvx/secure path, command substitution,
CLI process execution, and real secret-like values in fixtures.

## Test/build evidence

- Upstream `npm test` probe: `190 passed / 1 skipped`.
- The published `dist/` entrypoint is generated by the repository build script;
  the source revision therefore needs an explicitly allowlisted, offline build
  step or a separately frozen generated-output artifact.
- Lifecycle scripts are not accepted by the verifier default; `npm ci
  --offline --ignore-scripts` must be used and any required build must be
  separately reviewed.

## Blockers before `task.toml`

1. Produce and review an npm lockfile v3 and complete offline integrity closure,
   or approve an equivalent content-addressed package artifact.
2. Freeze the generated `dist/` provenance and build toolchain.
3. Implement a Node child-process adapter for parse/populate only.
4. Convert the upstream suite to a private structured `node:test` bundle and
   freeze collection in the final verifier image.
5. Run Oracle three times plus empty, stub, forgery, hang and offline controls.

The package remains a candidate, not a publishable benchmark task, until all
blockers are independently evidenced.
