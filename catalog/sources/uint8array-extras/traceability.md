The upstream AVA suite has 41 tests and passed at the frozen revision. The private 29-leaf `node:test` suite keeps the public behavior observable while moving all candidate imports and typed-object construction into the UID-separated child process.

| Contract | Coverage |
| --- | --- |
| Package identity, exports, dependency and script policy | 1 |
| Type guards and conversion boundaries | 2-9 |
| Concatenation, equality, comparison | 10-15 |
| UTF-8, ArrayBuffer and alternate encoding | 16-18 |
| Base64/Base64URL and string round trips | 19-23 |
| Hex conversion and errors | 24-26 |
| Big-endian reads and byte search | 27-29 |

The verifier owns collection, JUnit, network evidence and reward. Candidate code is never imported by the trusted test process.
