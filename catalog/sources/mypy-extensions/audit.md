## Verifier adaptation

Direct trusted imports are forbidden. The custom verifier uses the repository's
bounded candidate client to run one declarative behavior scenario per leaf as
UID 10001. Candidate installation uses a no-dependency, no-build-isolation,
bounded pip target install. Each child has CPU, address-space, process, file,
output, and wall-time limits, and candidate process groups are cleaned between
calls.

The verifier freezes 69 leaves. Expected values and leaf decisions stay in the
root-owned private bundle. Scenario programs contain operations only; they do
not contain expected values or grading logic. Reports, collection, JUnit, and
reward are generated by trusted code.
