# Audit Notes

The frozen source is a zero-runtime-dependency Node package. Its upstream tap
suite was executed during inventory; benchmark-only, exhaustive character, and
environment-sensitive checks were not copied into the private Harbor contract.
The 52 deterministic leaves retain coverage of the serializer's public API,
error behavior, and packaging boundary.

The verifier imports the candidate only in a UID 10001 child process. It owns
the collection, report, reward, and network evidence. The candidate cannot
write trusted logs, provide arbitrary package names, pass loader options, or
choose test commands.
