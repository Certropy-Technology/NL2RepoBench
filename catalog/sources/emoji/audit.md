# `emoji` production authoring record

The source is frozen to commit
`d26c675190a6b6c0edee959d7b896721a9c3641d`. Its unprefixed Git archive is
4,853,760 bytes with SHA-256
`0ab5a04e57bc580c66c78743cbfa413612f305bf151755ea72bddf5c9fb919ae`.
The source declares BSD-3-Clause licensing, package version 2.15.0, and no
third-party runtime dependencies.

The legacy same-process pytest projection is not the production contract. The
private custom verifier contains 25 finite scenarios for public package
metadata and signatures; English, alias, multilingual, delimiter, variant, and
version conversion; replacement; positions and counts; predicates and version
lookup; RGI and non-RGI ZWJ behavior; skin tones, flags, and keycaps; direct
lookup and language loading; token and match objects; errors; and empty input.
Only a constrained candidate subprocess imports candidate code. Trusted
expected observations and pass/fail decisions remain in the separate verifier.

The build dependency closure contains only `setuptools==80.10.2`, pinned by
wheel SHA-256 in a plain requirement lock. Docker build installs it with
`--require-hashes`; no wheel or wheelhouse is vendored. Agent and verifier run
phases are no-network. The Oracle contains only `solve.sh` and the frozen source
archive; it verifies the archive digest locally before extracting it.

Official Harbor 0.21.0 production gates completed. Oracle passed 25/25 with
`valid=true` and reward 1.0. Empty, installable stub, and reward-forgery
controls returned valid reward 0.0; stub and forgery each collected 25 leaves
and passed none. All four verifier network receipts report
`public_network_available=false`, with both `pypi.org:443` and `1.1.1.1:443`
unavailable.

The lifecycle stops at `controls-passed`. Reviews, pilots, dataset integration,
publication, commits, and pushes are outside this lane. Exact receipt paths and
SHA-256 values are in `evidence/controls-passed.json` and
`production-evidence.json`.
