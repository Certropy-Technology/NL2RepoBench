# Trove Classifiers task audit

The frozen project is an Apache-2.0 static-data Python package maintained by PyPA.
Its implementation consists primarily of 895 valid classifier strings, an eight-key
deprecation map, four public mutable containers, and a CLI that prints the ordered
valid list. The exact revision is also immutable tag `2026.6.1.19`.

An empty offline agent cannot fairly infer every future classifier spelling from the
package name alone. This task therefore does not hide an exact 895-row digest. The
public specification exposes all scored counts, structural invariants, deprecations,
ordering boundaries, and representative values. The verifier checks those documented
contracts and explicitly excludes exact unlisted rows.

The production verifier is separate and offline. Its trusted entrypoint never imports
candidate modules. Each data or metadata observation runs through the repository's
UID-10001 candidate child, and module/console invocations use the same bounded runner.
The 35 unique leaves provide partial credit without trusting candidate-written JUnit,
collection, grading, or reward files.
