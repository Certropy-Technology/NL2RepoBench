# Requests task audit

The frozen revision is a mature Apache-2.0 Python HTTP client with an
installable PEP 517 build and four declared runtime dependencies. The risky
network behavior is not mechanically exposed to the evaluator: the private
slice injects a deterministic local adapter and checks request construction,
response handling, cookies, authentication, hooks, redirects, and utilities.

The task remains a repository-generation task: the candidate starts empty and
must provide packaging, imports, runtime dependency declarations, public API
modules, and implementation. Hidden tests are separate from the candidate and
are executed through the custom JSON verifier boundary.
