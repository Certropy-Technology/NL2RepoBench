# NL2RepoBench Java/Maven Pilot

This is a separate Java/Maven pilot release. Its task versions, source
revisions, Harbor bundle digests, Oracle receipts, and controls are independent
of the existing Python, Node, Go, and historical Harbor datasets.

The three tasks currently have current Oracle and controls evidence and have
passed independent specification/security review. The release is currently
`pilot-blocked`: bounded Sol and Opus model attempts stalled during
Harbor/OpenHands initialization before producing a trajectory or result. It
must not be promoted to `published` until both model-run evidence and remote
image/toolchain reproducibility receipts are recorded.
